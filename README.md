# VQEAF OS

This repository is temporarily initialized to import the prepared VQEAF OS v2.4.1 Git history, including the signed Pixel Snake `.qeapp` template.

**Import is not complete yet.** Do not treat this temporary bootstrap commit as the firmware source. The verified import replaces this bootstrap branch with the original two prepared commits.

Hardware target: ESP32-S3-WROOM-1 N16R8, ST7789 portrait 240×320. Supported formats: `.vqeaf` themes and `.qeapp` apps.
